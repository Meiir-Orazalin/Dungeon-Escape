# Changelog

## v1.0.0 — Stable release

- Added pinned Chromium, Firefox, and WebKit release suites, forced-Canvas fallback coverage, lifecycle soak diagnostics, graceful capability/fatal handling, non-blocking audio boot, contrast checks, performance budgets, release audits, and final public documentation.
- Preserved the Phase 7 planning fixture, gameplay, balance, generated audio set, production domain, and dist-only Pages architecture.

## v0.7.0 — Presentation, audio, accessibility, and balancing

- Added original generated ambience/effects, Settings, onboarding, Field Manual, exact-state Pause, accessibility modes, health bars, low-health feedback, and the one-time 450 ms enemy awakening grace.

## v0.6.0 — Complete deterministic three-floor run

- Connected three independently planned floors with difficulty profiles, carry state, checkpoint replay, Floor Cleared transitions, victory/defeat, and eight-upgrade run builds.

## v0.5.0 — Deterministic loot and run upgrades

- Added Treasure Chests, Runic Shards, Vitality Flasks, deterministic enemy rewards, the Runeforge, six upgrades, and a separate loot fingerprint.

## v0.4.1 — Production deployment milestone

- Published the Phase 4 game through verified, HTTPS-enforced GitHub Pages deployment with canonical metadata, artifact audits, and bridge-free live smoke tests.

## v0.4.0 — Enemies and combat

- Added three deterministic enemy archetypes, sword combat, dash, health, defeat, and the encounter fingerprint while keeping enemies optional.

## v0.3.0 — Escape objective

- Added the deterministic Runic Key, Ancient Gate, interaction priority, objective fingerprint, completion overlay, and floor timer.

## v0.2.0 — Dungeon generation

- Added deterministic validated rooms/corridors, URL seeds, camera-followed worlds, discovery, minimap, and layout fingerprints.

## v0.1.0 — Foundation and movement

- Established the strict TypeScript/Phaser project, responsive shell, scene flow, keyboard movement, collision, tests, and quality gates.
